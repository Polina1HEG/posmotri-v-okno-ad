# Проектная работа «Посмотри в окно»

Проектная работа по вёрстке: дописать CSS для готового интерактивного приложения, которое показывает видеозаписи из разных городов в разное время суток.

## О проекте

Приложение «Посмотри в окно» позволяет пользователю выбрать город и время суток, после чего на странице отображается подборка видеороликов, снятых из окон. Ролики можно переключать кликом по карточкам в списке — выбранное видео подставляется в основной блок.

## Ссылка на проект

https://github.com/Polina1HEG/posmotri-v-okno-ad

## Что сделано

Вёрстка выполнена по шагам согласно заданию:
1. Лейаут — флекс-контейнер .page, центрирование .content по горизонтали и вертикали, расположение .result и .content__details в строку с прижатием к низу, фиксированная высота .content__list-container со скроллом.
2. Уточнение размеров — размеры .result__video-container, object-fit для видео, отступы через gap в списках, раскладка карточки, flex-grow для описания.
3. Стили текстов — оформление заголовков формы, .title и .content__accent, ссылки карточки, обрезка текста через text-overflow и line-clamp.
4. Формы — паттерн .visually-hidden, кастомные чекбоксы через ::after и :checked, стилизация текстового поля, состояния :hover и :focus-visible.
5. Кнопки — общий класс .button, индивидуальные стили .search-form__submit-button и .more-button, состояния :hover, :active, :focus-visible.
6. Состояния карточек — блочная ссылка, текущая карточка (.content__card-link_current), :active, :hover, :focus-visible, padding для обводки.
7. Кликабельность — cursor: pointer на интерактивных элементах.
8. Прелоадеры — position: relative на контейнерах видео и списка, абсолютное позиционирование прелоадеров.
